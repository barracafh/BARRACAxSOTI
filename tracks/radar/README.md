# Radar

**Estado:** si-hay-gente · **Track lead:** por asignar.

## Qué resuelve y para quién

Avisos de plazos de ayudas a partir de convocatorias públicas. Personas que pierden plazos de ayudas; track opcional, solo si hay gente.

## Piezas y criterio de hecho

Una pieza por squad, con 3,5 h de build y el pack preparado. Alcances propuestos para que los cierre el track lead.

| Pieza                        | Alcance en 3,5 h                                                              | Hecho cuando…                                                                                        |
| ---------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Plazos de ayudas             | Filtrar fechas del mismo extracto de convocatorias que Derechos.              | Distingue cierre conocido y sin fecha; cada plazo enlaza a la convocatoria.                          |
| Calendario descargable       | Exportar las convocatorias seleccionadas a un calendario .ics.                | El fichero se importa con título, fecha y fuente; se prueban zona horaria y fechas límite ficticias. |
| Alertas sin datos personales | Mostrar avisos locales de próximos cierres sobre una selección sin identidad. | Se ve qué vence y cuándo, sin correo, cuentas ni promesas de notificaciones persistentes.            |
